# Wordly

English learning app for A1–B2 learners: grammar, vocabulary, translation, quizzes and progress.

Live site: https://wordly-english-lab.hyunjett.chatgpt.site

Includes an English interface with light/dark themes and simple grammar explanations in Russian.

See [GUIDE.md](GUIDE.md) for setup and architecture. Built with React, TypeScript, Vinext and Cloudflare D1. The hosted version uses ChatGPT authentication; other hosting needs authentication and database configuration.
