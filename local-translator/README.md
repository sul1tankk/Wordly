# Локальный переводчик Wordly на Mac

Этот сервис переводит английский и русский через LibreTranslate на вашем Mac. У него нет дневной квоты MyMemory. Перевод работает, пока Mac включён, Docker запущен, а компьютер не спит.

1. Установите Docker Desktop для Mac и запустите его.
2. Скопируйте `.env.example` в `.env` и замените значение на длинный случайный секрет.
3. В папке `local-translator` выполните `docker compose up -d`.
4. Проверьте сервис командой `curl http://127.0.0.1:8080/translate`. Ответ `401` означает, что защищённый вход работает.
5. Для сайта нужен постоянный публичный HTTPS-адрес. Создайте бесплатный статический домен в ngrok и направьте его на `http://localhost:8080`.
6. Сохраните адрес в `LIBRETRANSLATE_URL`, а секрет из `.env` — в `LIBRETRANSLATE_TOKEN` в настройках Wordly Sites, затем опубликуйте новую версию.

Не публикуйте `.env` и не отправляйте секрет в GitHub.
