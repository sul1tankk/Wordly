# Wordly: как устроен сайт

Приложение для изучения английского A1–B2. Интерфейс — React и TypeScript, сервер — Vinext на Cloudflare Workers, данные — Cloudflare D1.

## Файлы
- `app/page.tsx`: интерфейс, словарь, квиз, упражнения, статистика.
- `app/content.ts`: 32 слова, 12 уроков, четыре истории и предложения для упражнений. Подборки имеют учебную, приблизительную маркировку CEFR, не являются полным курсом.
- `app/globals.css`: внешний вид и адаптация под телефон.
- `app/api/study/route.ts`: перевод, запись слов и результатов.
- `db/schema.ts` и `drizzle/`: схема базы и миграции.

## Перевод
Слова из учебной подборки переводятся локальным словарём. Остальные короткие фразы отправляются в MyMemory через сервер. Внешний сервис может ограничивать запросы или быть недоступен; интерфейс показывает ошибку и сохраняет введённый текст в поле. Перевод автоматически сохраняется в словарь, одинаковые английские записи объединяются. Квиз требует ввода сохранённого английского слова/фразы. У слова есть счётчик верных ответов; три верных ответа обозначаются как закрепление. Это не система интервального повторения.

## Прогресс и доступ
Записи хранятся в D1 отдельно для каждого пользователя. Идентификатор приходит от доверенной платформы Sites в `oai-authenticated-user-id`. Публичный сервер не должен принимать этот заголовок напрямую от посетителя. Сайт сейчас личный; доступ обеспечивает платформа ChatGPT. Локальный запуск без платформенного входа показывает учебные материалы, но API сохранения возвращает 401.

## Запуск кода на компьютере
Нужны Git, Node.js 22.13+ и менеджер pnpm указанной в package.json версии.
1. Скопировать исходный репозиторий проекта на компьютер.
2. `pnpm install`
3. `pnpm build`
4. Для локальной базы применить миграцию через `pnpm exec wrangler d1 execute DB --local --persist-to .wrangler/state --config dist/server/wrangler.json --file drizzle/0000_living_scalphunter.sql`.
5. `pnpm dev`

Для полноценной самостоятельной разработки вне ChatGPT потребуется настроить собственный вход и защищённую выдачу пользовательского идентификатора. Нельзя просто отключить проверку входа на публичном сервере.

## GitHub
GitHub необязателен для уже размещённого сайта. Он удобен для истории изменений, работы в VS Code и портфолио. Код сейчас сохранён в Git-репозитории, связанном с Sites; отдельный GitHub-репозиторий не создавался.

Чтобы перенести копию на GitHub: создать пустой приватный репозиторий; добавить его как второй remote `github`; отправить текущую ветку. Не публиковать `.env`, ключи, токены, `.wrangler`, `node_modules` и пользовательскую базу. Не заменять существующий remote Sites. Не создавать новый Site при обычном редактировании.

GitHub Pages подходит для статических страниц и не запускает этот сервер или D1. Для переноса живого приложения нужны совместимый серверный хостинг, база данных и отдельная настройка авторизации. Загружать один `index.html` недостаточно.
